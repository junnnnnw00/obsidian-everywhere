# Obsidian Everywhere v0.9.1 — MCP Registry metadata fix

v0.9.1 is a metadata-only follow-up to v0.9.0. It shortens the public server
description to the MCP Registry's 100-character limit and adds a release
preflight check so the same mismatch is caught before publishing.

All reviewable Vault Git functionality, safeguards, documentation, and
cross-platform verification from v0.9.0 are unchanged. See the
[v0.9.0 release notes](https://github.com/junnnnnw00/obsidian-everywhere/releases/tag/v0.9.0)
for the complete feature overview.
