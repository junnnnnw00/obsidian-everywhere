# Obsidian Everywhere v0.8.1 — Larger attachment limits

This patch raises the conservative v0.8.0 extraction limits and makes them
operator-configurable.

- Source attachments: 32 MiB → 64 MiB by default.
- PDFs: 16 MiB → 48 MiB by default.
- Uncompressed Office/OpenDocument/EPUB entries: 8 MiB → 32 MiB by default.
- Each limit can be raised independently up to 1 GiB with documented
  environment variables.

The default values retain the project's 200 MiB RSS smoke-test target. Raising
them is useful for larger research documents but may require more process
memory.
