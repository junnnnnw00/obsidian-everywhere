# Obsidian Everywhere v0.9.2 — Reliable attachment discovery

v0.9.2 makes attachment access more reliable for remote MCP agents, especially
when a vault lives on a removable drive or network mount.

## Highlights

- `search_files` now combines case-insensitive filename and vault-relative path
  matching with extracted-text search.
- Ordinary filenames containing punctuation, such as `final.pptx`, no longer
  fail as invalid full-text-search expressions.
- Folder, extension, and file-type filters are applied before the search limit,
  so unrelated notes cannot crowd attachments out of scoped results.
- An exact `read_file` path can safely index one existing file that a filesystem
  watcher has not observed yet.
- Mount Guard now recreates the filesystem watcher after a mount returns, waits
  for its initial walk, and then performs transactional reconciliation.
- Temporary Microsoft Office owner files such as `~$deck.pptx` are excluded
  from indexing and removed from existing indexes during reconciliation.

## Safety

Exact-path recovery rejects traversal, excluded paths, and symlink escapes. It
also observes Mount Guard before and after indexing, rolling back if the vault
becomes unavailable.

## Upgrade

```bash
npm install -g obsidian-everywhere@0.9.2
```

Restart the local MCP service after upgrading. Existing vault indexes require
no manual migration or rebuild.
