# Obsidian Everywhere v0.8.0 — Vault-wide attachment access

v0.8.0 lets MCP clients read and search knowledge stored outside Markdown
notes while preserving the vault graph around those files.

## Highlights

- New `read_file` and `search_files` tools.
- Local extraction for PDF, DOCX, PPTX, XLSX, OpenDocument, EPUB, RTF,
  text/code/data formats, and common images.
- Page, slide, and sheet selection with attachment backlinks.
- Lazy, sequential, hash-keyed extraction caching with strict input and output
  limits.
- A repeatable 200 MiB RSS gate; the release fixture peaks near 120 MiB.
- Transformer semantic search is now an optional peer and explicit opt-in, so
  the default install is lighter and has zero production audit findings.

## Upgrade

```bash
npm install -g obsidian-everywhere@0.8.0
```

Existing source-checkout and `npx` users only need to restart their MCP client
or service after upgrading. Attachment extraction happens on demand and does
not require a migration command.
